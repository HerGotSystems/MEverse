# MY CYCLE — MVP acceptance tests

- [ ] App starts without account, email, age, name, phone number or internet access after installation.
- [ ] New profile chooses encryption passphrase and explains irrecoverability.
- [ ] Mark/unmark period day, flow, symptoms and private note.
- [ ] Past records persist across reload / restart and remain encrypted at rest.
- [ ] Predictions can be disabled; default estimates state uncertainty and avoid firm claims.
- [ ] Fertility options OFF by default, not used in period notifications.
- [ ] Entries never uploaded or transmitted, including via analytics or crash logs.
- [ ] Encrypted backup, restore on a separate device, wrong-passphrase rejection, damaged-backup rejection.
- [ ] Safe retention when storage is almost full; no silent data loss.
- [ ] Delete all with confirmation, and explain limits regarding other backups.
- [ ] English and Czech UI and user-facing medical text reviewed.
- [ ] Daylight-saving transitions, leap years and timezone changes do not corrupt logged days.
- [ ] Screen reader labels, keyboard operation, touch targets, contrast and reduced motion tested.
- [ ] Small phones, Android Chrome and iOS Safari installed web app tested.
- [ ] No notification until explicit opt-in; neutral notification wording.
- [ ] No genuine user's personal data in test fixtures, telemetry or GitHub.
- [ ] Legal/privacy copy reviewed for intended jurisdictions and under-18 users.

Current status: this is a checklist, not proof of passing tests.
